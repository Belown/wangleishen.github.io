When I started working with silicone, I expected to learn about materials. I learned more about patience. A soft actuator takes four seconds to fill, and in those four seconds you notice your own breathing.<sup><a className="fnref" href="#fn-1">1</a></sup>

### Hard by default

Almost everything we touch on a screen is designed to stay the same under the finger. That is useful, and it is also lonely. Nothing pushes back, nothing gives way.

<Img file="journal/soft-machines/hero.jpg" note="Wide photo: the actuator array on the bench" caption="The second Softfold prototype, half inflated." />

Soft interfaces change the question from “did it register?” to “how did it feel?”. That is a harder question to put in a results table.<sup><a className="fnref" href="#fn-2">2</a></sup>

<Quote cite="Lab notebook, March 2026">A machine that can be squeezed is a machine that can be comforted.</Quote>

The control loop is almost embarrassingly simple:

```cpp
// hold pressure when the wearer squeezes back
if (squeeze > THRESHOLD) {
  valve.close();
  pump.setPressure(HOLD_KPA);
} else {
  pump.setPressure(REST_KPA);
}
```
